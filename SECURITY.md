# Security Policy

## Supported Versions

Security fixes are provided for the latest released minor version.

| Version | Supported |
| ------- | --------- |
| 0.2.x   | ✅        |
| 0.1.x   | ❌        |

## Reporting a Vulnerability

Please report security issues privately through GitHub's
[private vulnerability reporting](https://github.com/neko233-com/phone-lib-go/security/advisories/new)
instead of opening a public issue.

Please include:

- the affected version (`phone.Version`),
- a minimal reproduction (input number, country hint, options),
- the observed and expected output,
- any relevant environment details (OS, Go version).

You can expect an initial response within a few days. Once a fix is ready, a
new patch release is tagged and the advisory is published with credit (unless
you prefer to remain anonymous).
